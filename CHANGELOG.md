## [Unreleased]

### Added

- Portfolio README, MIT license, contribution guide, code of conduct and security policy.
- Continuous integration (byte-compilation and secret scan) and a release workflow.

## [1.0.0] - 2023-06-05

First tagged version: the game as built for the course.

### Added

- Console Minesweeper with three difficulty levels and 30 or 40 square grids.
- Recursive uncovering of empty areas, flags, move counter and timer.
- Session scoreboard sorted by time, and replay prompt.
